Audits
======

Post-release assurance documents. These are **additive**: an audit never
modifies the tag, appendix, or artifact it reviews.

An audit whose verdict is unsigned is not a passing audit. The distinction
between *evidence produced* and *verdict rendered* is deliberate — evidence
produced by the author of the reviewed code is useful but does not establish
independence.

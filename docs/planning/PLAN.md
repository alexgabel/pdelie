## Release Theme

`v0.23` adds downstream provenance diagnostics:

> user-supplied partition labels + FieldBatch/orbit-batch provenance -> JSON-compatible split provenance report -> leakage-risk diagnostics -> optional downstream workflow summary integration

The public claim is intentionally narrow. The release reports traceability and detectable overlap. It does not add split creation, leakage prevention, train/test management, benchmark policy, downstream success criteria, automatic augmentation policy, file loaders, Dataset support, new PDEs, KS promotion, weak-form expansion, time translation, neural/callable generator APIs, operator APIs, or root exports.

## Milestone 1 - Semantics Freeze

Frozen public helper:

```python
pdelie.reporting.summarize_split_leakage_provenance(
    *,
    partitions,
    orbit_batch=None,
    source_ids=None,
    sample_metadata=None,
    source_report_id=None,
    extra_metrics=None,
)
```

Frozen interpretation:

- partitions are user-supplied metadata, not generated by PDELie
- partition labels are non-empty strings; PDELie does not require a fixed label set
- risk labels are `no_detected_overlap`, `traceable_overlap`, `missing_provenance`, and `inconclusive`
- `OrbitBatchResult` and `uniform_translation_orbit_batch` reports are accepted provenance sources
- source/shift provenance is read from existing `source_batch_indices` and `shift_indices`
- optional metadata must be strict JSON-compatible
- no split creation, no leakage prevention, no benchmark policy, no automatic augmentation policy, and no downstream success criteria

## Milestone 2 - Split Provenance Helper

Implemented:

- `pdelie.reporting.summarize_split_leakage_provenance(...)`

The helper validates partition labels, sample counts, optional source IDs, optional sample metadata, orbit-batch provenance reports, and strict JSON compatibility. It reports source overlap, source-and-shift overlap, identity-shift overlap, partition-pair counts, component statuses, and risk reasons.

## Milestone 3 - Orbit-Batch Risk Coverage

Implemented tests for:

- traceable materialized orbit batches with source/shift indices enabled
- missing provenance when source/shift indices are disabled
- duplicate shifts and identity shifts
- source-only overlap
- same-source/same-shift overlap
- report-only behavior with no transformed `FieldBatch` objects returned

## Milestone 4 - Workflow Integration And Example

Implemented:
